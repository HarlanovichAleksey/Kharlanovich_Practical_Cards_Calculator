# Практическая работа №5 — Калькулятор визиток (JS + Объекты)

**Автор:** Харланович Алексей, ПИУКИС-23

## Описание
Калькулятор для расчёта стоимости изготовления визиток. Проект выполнен на чистом **JavaScript** (без использования jQuery) с применением объектов для хранения прайс-листа. Дизайн — строгий тёмный интерфейс.

## Что реализовано
- **Интерфейс:** поля для ввода тиража, выбора типа бумаги и цветности.
- **Объекты в JS:** созданы три объекта (`prices.template`, `prices.paper`, `prices.print`), хранящие цены.
- **Динамическая картинка:** при изменении цветности меняется изображение-превью визитки (берется из папки `img/`).
- **Расчёт:** функция `calculate()` автоматически пересчитывает стоимость при любом изменении полей.
- **Формула:** `Стоимость = Цена шаблона + (Цена бумаги * Тираж/30) + (Цена печати * Тираж/30)`.
- **Стиль:** современный тёмный дизайн с аккуратной типографикой.

## Технологии
- HTML5
- CSS3 (Flexbox, темная тема)
- JavaScript (ES6, работа с объектами, DOM)
